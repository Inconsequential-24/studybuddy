name: StudyBuddy visual direction
description: The product's visual tone and motion preference.
---

Keep StudyBuddy's interface simple, professional, and classy. Use restrained loading motion, and make it static or remove it when reduced motion is enabled.

**Why:** The user requested a simple professional product and specifically asked that loading animation respect accessibility settings.

**How to apply:** Favor clear layouts and subtle animation for StudyBuddy screens; preserve status text and progress information when motion is disabled.

Dyslexia support is opt-in: use OpenDyslexic only when selected, and make the reading ruler a separate optional control.

**Why:** The user asked for dyslexia-specific settings to activate only by choice and noted that a reading ruler is helpful for some, not mandatory for everyone.

**How to apply:** Keep these settings independent from general accessibility mode and off by default; do not present either as a universal accommodation.
